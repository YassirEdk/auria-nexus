# AURIA Nexus

Build a premium, modern and highly convincing corporate website for an international trading and sourcing company called AURIA.

BRAND POSITIONING

AURIA is a China-based international trading company that connects businesses worldwide with reliable manufacturers, suppliers and production partners in China.

AURIA provides end-to-end services including:

Global product sourcing

Supplier and factory verification

Price negotiation

Sample sourcing

Quality control and inspection

Production monitoring

Private label and custom manufacturing

Product development

Warehousing and consolidation in China

International shipping and logistics coordination

Factory and supplier visits

Complete China-to-global procurement solutions

The website must communicate:
Trust + International scale + Premium quality + Chinese manufacturing expertise + Reliability + Technology.

The visitor should immediately feel:

"These people can handle my entire sourcing and trading operation in China."

DESIGN DIRECTION

Create a luxury B2B corporate website inspired by premium technology companies, international logistics companies and high-end consulting firms.

Avoid:

Generic corporate templates

Cheap-looking gradients

Excessive text

Stock-photo-heavy layouts

Overly colorful designs

Cartoon-style graphics

Excessive animations

Use a sophisticated visual identity.

Suggested palette:

Deep black / charcoal

Warm off-white

Metallic champagne / subtle gold accents

Very subtle dark blue-gray accents

The AURIA logo should feel elegant, minimal and premium.

Typography:
Use a modern luxury sans-serif such as Inter, Manrope, Satoshi or Geist.
Large typography, generous spacing and strong visual hierarchy.

ANIMATION SYSTEM

Animations are very important, but they must remain professional.

Use:

Framer Motion

GSAP where appropriate

React Three Fiber / Three.js for 3D

Intersection Observer for scroll reveals

Animations should include:

Smooth page loading animation

Logo fade-in

Hero text stagger animation

3D globe movement

Mouse-based parallax

Scroll-triggered section reveals

Card hover depth

Animated supply-chain lines

Smooth number/text transitions

Magnetic CTA buttons

Subtle image zoom on scroll

Smooth page transitions

Keep animation duration generally between 300ms and 900ms.

Avoid excessive bouncing, spinning or flashy effects.

The website must remain fast and responsive.

RESPONSIVE DESIGN

The website must be fully responsive.

Desktop:
Very immersive 3D experience.

Tablet:
Reduce 3D complexity.

Mobile:
Prioritize performance and readability.
Use simplified 3D animations or static fallback if necessary.

Navigation becomes a premium mobile menu.

All buttons and forms must be easy to use on mobile.

UX / CONVERSION

The website should be designed to convert visitors into business leads.

Primary conversion:
Start a Partnership

Secondary:
Request a Quote

Keep CTAs visible throughout the page without becoming annoying.

Use clear hierarchy and strong whitespace.

Every section should answer one question:

What industries do you serve?

How can I work with you?

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
