# AURIA premium international trading website

## Experience
- Build a cinematic, dark luxury website with champagne accents, warm editorial sections, large typography, and restrained glass/metal details.
- Make the opening screen immediately communicate China-based sourcing, manufacturing, quality control, and worldwide delivery.
- Add a minimal sticky navigation with desktop and mobile states, smooth movement, and clear partnership/quote actions.

## Pages and content
- Home: immersive trade-globe opening, qualitative trust markers, company introduction, eight services, five-step workflow, global network, industries, advantages, cinematic manufacturing feature, conversion section, and inquiry form.
- Add dedicated About, Services, Industries, How We Work, and Contact pages so navigation destinations are shareable and search-friendly while retaining the complete home experience.
- Use only the supplied claims and qualitative metrics; keep contact details as clearly replaceable placeholders.

## Visuals and interaction
- Create an original WebGL globe with China as the hub, animated routes, particles, atmospheric lighting, subtle mouse response, and reduced complexity on smaller screens.
- Create an original cinematic manufacturing/trade visual using generated imagery, layered motion, and subtle digital route treatments.
- Add restrained scroll reveals, card depth, supply-chain line animation, horizontal industry movement, magnetic-feeling CTAs, and reduced-motion fallbacks.

## Technical details
- Use React, TanStack Start, Tailwind CSS v4 tokens, Motion for React, Three.js, React Three Fiber, and Drei.
- Build reusable navigation, footer, globe, section, service-card, process, CTA, and contact components.
- Lazy-load the WebGL experience and provide a static visual fallback for constrained devices.
- Add unique metadata to every public page, semantic structure, keyboard/focus states, accessible labels, and responsive layouts.
- Validate desktop and mobile rendering, navigation, form behavior, reduced-motion behavior, and runtime console output.
